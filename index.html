Desktop Application - GUI of Basic Petrophysics Code

IIT (ISM) Dhanbad

August 2024 – November 2024

Objective: Developed a Python-based GUI application to perform and visualize petrophysical analysis, enabling geoscientists to streamline workflows for reservoir characterization and well log interpretation.

Key Features:

  • User Interface: Intuitive GUI for inputting petrophysical parameters (porosity, permeability, water saturation). Interactive data visualization including multi-track logs, histograms, and cross-plots.
  • Core Functionality: Automated calculations for Archie’s equation, shale volume, effective porosity, and parameter sensitivity analysis with real-time sliders.
  • Visualization: Depth-dependent log plotting, dynamic cross-plots (porosity vs. resistivity, saturation vs. permeability), and export-ready figures for reports.
  • Data Handling: Import/export support for industry-standard file formats (LAS, CSV, XLSX).

Technology Stack:

  • GUI Frameworks: PyQt5, Tkinter (for standalone deployment).
  • Backend: Python modules for petrophysical computations and Matplotlib/Seaborn for visualization.
